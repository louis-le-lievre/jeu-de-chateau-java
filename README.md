# Jeu de Château

Jeu de stratégie développé en Java dans le cadre d'un projet en équipe à l'EPF.

## Fonctionnalités
- Interface graphique
- Déplacements et captures selon les règles du jeu
- Jeu contre un adversaire informatique
- Sauvegarde et chargement d'une partie

## Technologies
- Java
- NetBeans

## Lancement
Ouvrir le projet dans NetBeans, puis compiler et exécuter le projet.
